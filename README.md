# Minimal ML

Interview preparation for senior machine learning engineer, AI engineer and research engineer roles, built
from what currently open postings ask for, on top of concise, executable notes that explain machine learning
from first principles.

- Website: <https://threeeyelidds.github.io/minimal-ml/>
- Repository: <https://github.com/threeeyelidds/minimal-ml>

## What is in the site

| Section | Source | What it is |
|-|-|-|
| Report | `report/index.qmd`, `report/_prose/` | What the postings ask for, by track, role type, employer and level |
| Skills | `bank/*.yml` → `skills/` | One page per skill area: demand, senior bar, checklist, questions with answers |
| Review | `bank/*.yml` → `review/` | The same cards with spaced repetition, mock rounds and readiness per track |
| Reported questions | `bank/reported.yml` → tags on cards, a section of the report | Questions that third-party sites list as asked in interviews, matched to cards; unverified |
| Plan | `plan/index.qmd` | Order of areas per track, schedule, daily loop |
| Open roles | `data/postings.json` → `jobs/` | The postings, filterable by track, role type and skill |
| Notes, Essays | `notes/`, `essays/` | Long-form deep dives |

`skills/`, `review/index.qmd`, `review/skills.js`, `jobs/postings.js`, `report/_gen/` and `_variables.yml` are
generated by `tools/build_site.py`, which Quarto runs before every render. Edit the sources, not those files.

## Setup

Install Quarto and uv, then:

```bash
uv sync
uv run quarto preview
```

If `quarto` is installed system-wide rather than inside the Python environment, use:

```bash
uv sync
quarto preview
```

## Adding or changing questions

Cards live in `bank/<area>.yml`; the format and writing rules are in `bank/README.md`.

```bash
.venv/bin/python tools/validate_bank.py   # format, skill ids, every skill covered, reported.yml
quarto preview                            # rebuilds the skill pages and the review app
```

## Refreshing the job data

```bash
python3 tools/fetch_jobs.py             # Greenhouse / Ashby / Lever boards -> data/raw/ (not committed)
python3 tools/fetch_jobs_bigtech.py     # employers with their own career sites
python3 tools/analyze_skills.py         # -> data/skills.json, data/postings.json, data/summary.json
```

The skill list and its match patterns are in `tools/taxonomy.py`. Prose in the report reads its numbers from
`_variables.yml`, so it follows the data; reread the report's sentences after a refresh in case a comparison
has flipped.

## Writing notes

- Use `.qmd` for conceptual notes with math + short executable examples.
- Use `.ipynb` for exploratory experiments.
- Use `.py` for implementations you want to test like real software.
