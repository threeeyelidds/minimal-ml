Attention

Intuition

Compared to MLP, attention uses input-dependent mixing weights rather than a fixed learned weight matrix. The attention weight \(w_{ij}\) measures how strongly the query representation \(q_i\) matches the key representation \(k_j\).
For each output token \(o_i\), it is a weighted sum of the value sequence tokens \(v_j\), weighted by softmax-normalized similarity scores between the query token \(q_i\) and each key token \(k_j\). So intuitively:

query→which positions matter?
keys→what does each position match on?
values→what information gets retrieved?

SDPA

Derivation

Given query, key, and value matrices,

\[ Q \in \mathbb{R}^{n_q \times d}, \quad K \in \mathbb{R}^{n_k \times d}, \quad V \in \mathbb{R}^{n_k \times d_v}, \]

scaled dot-product attention is

\[ \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\left(\frac{QK^T}{\sqrt d}\right)V. \]

Minimal PyTorch implementation

import math
import torch


def attention(q, k, v, mask=None):
    scores = q @ k.transpose(-2, -1) / math.sqrt(q.shape[-1])

    if mask is not None:
        scores = scores.masked_fill(~mask, float("-inf"))

    weights = torch.softmax(scores, dim=-1)
    return weights @ v

Why Scale Dot-Product Attention by \(\sqrt{d_k}\)?

Why does a larger \(QK^T\) make softmax more peaked?

Softmax depends on the difference between logits, not whether all logits are large.

\[ \operatorname{softmax}(x_i) = \frac{e^{x_i}} {\sum_{j=1}^{n} e^{x_j}} \]

For example:

\[ \operatorname{softmax}([1,2,3]) \approx [0.09, 0.24, 0.67] \]

but

\[ \operatorname{softmax}([10,20,30]) \approx [0,0,1]. \]

Softmax is invariant to adding a constant:

\[ \operatorname{softmax}(x) = \operatorname{softmax}(x+c), \]

but not to multiplying by a constant:

\[ \operatorname{softmax}(\alpha x) = \operatorname{softmax}\left(\frac{x}{T}\right), \qquad T=\frac{1}{\alpha}. \]

So increasing the spread of the logits is equivalent to lowering the softmax temperature, which makes the distribution more peaked.

Why does \(q^T k\) grow with dimension?

Assume each component is approximately zero-mean with unit variance:

\[ q_r, k_r \sim (0,1). \]

Then

\[ q^T k = \sum_{r=1}^{d_k} q_r k_r. \]

If the terms are approximately independent,

\[ \operatorname{Var}(q^T k) \approx d_k, \]

so

\[ \operatorname{Std}(q^T k) \approx \sqrt{d_k}. \]

The scores do not all become large positive numbers. Instead, their spread grows with \(\sqrt{d_k}\), which makes softmax increasingly saturated (peaked).

Therefore attention uses

\[ \frac{q^T k}{\sqrt{d_k}} \]

so that the logit scale stays roughly constant as \(d_k\) changes.

Intuition: \(1/\sqrt{d_k}\) is variance normalization, not vector normalization.

Why Not Use Cosine Similarity?

Cosine similarity is

\[ \frac{q^T k}{\|q\|\|k\|}. \]

Since

\[ q^T k = \|q\|\|k\|\cos\theta, \]

dot-product attention can use both:

  • direction / alignment
  • vector magnitude

Cosine similarity removes the magnitude information.

This matters because \(Q\) and \(K\) are learned specifically for attention:

\[ q_i = x_iW_Q, \qquad k_j = x_jW_K. \]

The model may therefore learn useful information in their norms.

For random high-dimensional vectors,

\[ \|q\| \approx \sqrt{d_k}, \qquad \|k\| \approx \sqrt{d_k}, \]

so

\[ \frac{q^T k}{\|q\|\|k\|} \approx O\left(\frac{1}{\sqrt{d_k}}\right). \]

Cosine similarities therefore concentrate near zero as dimension grows, so cosine attention usually needs an additional temperature parameter to control softmax sharpness.

Interview Takeaway

Scaled dot-product attention uses

\[ \operatorname{softmax} \left( \frac{QK^T}{\sqrt{d_k}} \right)V. \]

The \(1/\sqrt{d_k}\) term keeps the variance of attention logits roughly constant as head dimension grows, preventing softmax saturation while preserving magnitude information in \(Q\) and \(K\).

Interview questions

  • Why is the scaling factor \(1/\sqrt d\) rather than \(1/d\)?
  • What happens to gradient flow when attention logits become very large?
    • Softmax saturation. Gradients vanish for Q and K, but not for V. The routing becomes fixed.
  • What are the time and memory complexities of standard attention?
  • What does FlashAttention change, and what does it leave mathematically unchanged?

Multi-Head Attention (MHA)

Motivation

Attention can be viewed as factorizing interaction into token mixing and feature mixing. MHA gives different feature subspaces different token-mixing operators.

In single-head attention, the same token-mixing scalar \(A_{ij}\) is shared across all feature dimensions. Multi-head attention relaxes this by introducing a head dimension, \(A_{ij}^{(h)}\), so different feature subspaces can use different attention weights. In this sense, heads are an efficient way to make token mixing conditional on the representation subspace, without paying the cost of fully feature-dependent routing \(A_{ijc}\).

Instead of performing one attention operation with the full model dimension, multi-head attention projects the input into \(h\) different query, key, and value subspaces:

\[ Q_i = XW_i^Q, \qquad K_i = XW_i^K, \qquad V_i = XW_i^V. \]

Each head independently computes

\[ \operatorname{head}_i = \operatorname{Attention}(Q_i,K_i,V_i), \]

and the results are concatenated and projected:

\[ \operatorname{MHA}(X) = \operatorname{Concat}(\operatorname{head}_1,\ldots,\operatorname{head}_h)W_O. \]

Low-Rank Note

For each head,

\[ S^{(h)} = Q^{(h)}K^{(h)T} \]

and therefore

\[ \operatorname{rank}(S^{(h)}) \le d_h. \]

So each head’s pre-softmax token-interaction matrix is low-rank when \(d_h \ll T\).

Minimal PyTorch implementation

import torch.nn as nn


class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0

        self.d_model = d_model
        self.num_heads = num_heads
        self.d_head = d_model // num_heads

        self.qkv_proj = nn.Linear(d_model, 3 * d_model, bias=False)
        self.out_proj = nn.Linear(d_model, d_model, bias=False)

    def forward(self, x, mask=None):
        batch_size, seq_len, _ = x.shape

        # (B, T, 3 * D) -> three tensors of shape (B, T, D)
        q, k, v = self.qkv_proj(x).chunk(3, dim=-1)

        # (B, T, D) -> (B, H, T, D_h)
        def split_heads(tensor):
            return tensor.view(
                batch_size, seq_len, self.num_heads, self.d_head
            ).transpose(1, 2)

        q, k, v = map(split_heads, (q, k, v))

        # mask must be broadcastable to (B, H, T, T), where True means allowed.
        head_outputs = attention(q, k, v, mask=mask)

        # (B, H, T, D_h) -> (B, T, D)
        output = head_outputs.transpose(1, 2).contiguous().view(
            batch_size, seq_len, self.d_model
        )
        return self.out_proj(output)

Causal Masking

In autoregressive self-attention, token \(i\) must not attend to future tokens \(j>i\).

\[ M_{ij} = \begin{cases} 0, & j \le i, \\ -\infty, & j > i. \end{cases} \]

The mask is applied before softmax:

\[ A = \operatorname{softmax}\left( \frac{QK^T}{\sqrt{d_k}} + M \right). \]

Minimal implementation

The attention function above uses a Boolean mask where True means that attention is allowed.

def causal_mask(seq_len, device=None):
    return torch.ones(
        seq_len, seq_len, dtype=torch.bool, device=device
    ).tril()


mask = causal_mask(seq_len=4)

        [ True,  True, False, False],
        [ True,  True,  True, False],
        [ True,  True,  True,  True]])

For multi-head attention, (T, T) broadcasts across the batch and head dimensions:

out = mha(x, mask=causal_mask(x.shape[1], x.device))

Multi-Query Attention (MQA) and Grouped-Query Attention (GQA)

MHA gives each query head its own key and value heads. MQA shares one key head and one value head across all query heads. GQA is the interpolation between them.

Variant Query heads KV heads Group size
MHA \(h\) \(h\) \(1\)
GQA \(h\) \(g\), where \(1<g<h\) \(h/g\)
MQA \(h\) \(1\) \(h\)

Using \(h_q\) query heads and \(h_{kv}\) key/value heads:

\[ Q \in \mathbb{R}^{B \times h_q \times T_q \times d_h}, \]

\[ K,V \in \mathbb{R}^{B \times h_{kv} \times T_{kv} \times d_h}, \qquad h_q \bmod h_{kv}=0. \]

Each KV head serves

\[ n_{\text{rep}} = \frac{h_q}{h_{kv}} \]

query heads.

Implementation skeleton

def repeat_kv(x, num_repeats):
    """Expand (B, H_kv, T, D_h) to (B, H_q, T, D_h)."""
    if num_repeats == 1:
        return x

    batch_size, num_kv_heads, seq_len, d_head = x.shape
    return (
        x[:, :, None, :, :]
        .expand(batch_size, num_kv_heads, num_repeats, seq_len, d_head)
        .reshape(batch_size, num_kv_heads * num_repeats, seq_len, d_head)
    )

Attention Optimization Methods

FlashAttention

Standard attention materializes the \(T \times T\) score and probability matrices in high-bandwidth memory (HBM). FlashAttention computes exact attention in tiles and uses an online softmax so these full intermediate matrices do not need to be stored in HBM.

Key distinction: FlashAttention changes the algorithm’s memory access pattern, not the mathematical definition of attention.

KV Caching

During autoregressive generation, previously computed keys and values do not change. Cache them instead of recomputing them at every decoding step.

At decoding step \(t\):

\[ K_{1:t} = \operatorname{Concat}(K_{1:t-1}, k_t), \qquad V_{1:t} = \operatorname{Concat}(V_{1:t-1}, v_t). \]

The new query attends to the cached prefix:

\[ o_t = \operatorname{softmax}\left( \frac{q_tK_{1:t}^T}{\sqrt{d_h}} \right)V_{1:t}. \]

Implementation skeleton

def append_to_kv_cache(k_new, v_new, cache=None):
    """A simple educational cache; production systems preallocate storage."""
    if cache is None:
        return k_new, v_new

    k_cache, v_cache = cache
    k_cache = torch.cat([k_cache, k_new], dim=-2)
    v_cache = torch.cat([v_cache, v_new], dim=-2)
    return k_cache, v_cache
