Transformer Architecture

1. High-Level View

A Transformer block alternates between:

  1. Token mixing via attention
  2. Feature mixing via the MLP

For hidden states

\[ X \in \mathbb{R}^{B \times T \times d_{\text{model}}}, \]

a modern pre-norm Transformer block is roughly

\[ X' = X + \operatorname{Attention}(\operatorname{Norm}(X)) \]

\[ X_{\text{out}} = X' + \operatorname{MLP}(\operatorname{Norm}(X')). \]

NoteCore intuition
  • Attention mixes information across tokens.
  • The MLP mixes information across features within each token.
  • Residual connections preserve and incrementally update the residual stream.

3. Normalization

LayerNorm

\[ \operatorname{LN}(x) = \gamma \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta. \]

RMSNorm

\[ \operatorname{RMSNorm}(x) = \gamma \frac{x} {\sqrt{\frac{1}{d}\sum_i x_i^2+\epsilon}}. \]

Pre-Norm vs Post-Norm

Post-norm

\[ X_{l+1} = \operatorname{Norm} \left( X_l + F(X_l) \right) \]

Pre-norm

\[ X_{l+1} = X_l + F(\operatorname{Norm}(X_l)). \]

5. Feed-Forward Network

The MLP operates independently on each token.

Classic Transformer FFN:

\[ \operatorname{FFN}(x) = W_2 \sigma(W_1x). \]

Typical dimensions:

\[ d_{\text{model}} \rightarrow d_{\text{ff}} \rightarrow d_{\text{model}}. \]

Usually

\[ d_{\text{ff}} > d_{\text{model}}. \]

SwiGLU

Modern LLMs often use gated MLPs:

\[ \operatorname{SwiGLU}(x) = W_o \left[ \operatorname{SiLU}(W_gx) \odot (W_ux) \right]. \]

TODO: - Why gating helps - Why SwiGLU replaced ReLU/GELU FFNs in many LLMs - Parameter-count implications

NoteAttention vs MLP

Attention:

\[ [B,T,d] \rightarrow \text{mix across } T \]

MLP:

\[ [B,T,d] \rightarrow \text{mix across } d \]

This is a useful way to think about a Transformer as alternating token mixing and feature mixing.

7. Full Decoder-Only Transformer

Pipeline:

\[ \text{tokens} \rightarrow \text{embeddings} \rightarrow L \times \text{Transformer blocks} \rightarrow \text{final norm} \rightarrow \text{LM head} \rightarrow \text{logits}. \]

For vocabulary size \(V\),

\[ X_L \in \mathbb{R}^{B\times T\times d} \]

and

\[ \text{logits} = X_L W_{\text{vocab}} \in \mathbb{R}^{B\times T\times V}. \]

10. Modern LLM Block

A typical modern decoder block looks roughly like:

x
│
├── RMSNorm
│
├── Attention
│
└── + residual
    │
    ├── RMSNorm
    │
    ├── SwiGLU MLP
    │
    └── + residual

Common modern choices:

  • decoder-only architecture
  • pre-norm
  • RMSNorm
  • RoPE
  • SwiGLU
  • GQA
  • FlashAttention
  • KV cache
